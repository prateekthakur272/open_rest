# Keyboard shortcuts

**Primary** means ⌘ on macOS and Ctrl on Windows and Linux.

| Keys | Action |
|---|---|
| Primary+K (or P) | Command palette |
| Primary+Enter | Send the request. On a WebSocket tab: connect, or send the message when connected |
| Primary+S | Save |
| Primary+Shift+S | Save all |
| Primary+N | New request (new collection if none is open) |
| Primary+W | Close tab |
| Primary+B | Show / hide the sidebar |
| Primary+L | Focus the URL bar |
| Primary+Shift+L | Switch between stacked and side-by-side layout |
| Primary+Shift+C | Copy as cURL |
| Primary++ / Primary+− / Primary+0 | Zoom in / out / actual size |
| Primary+, | Preferences |
| Primary+Q | Quit (Ctrl+Q on Windows and Linux) |
| Primary+M | Minimize (macOS) |
| Ctrl+Tab / Ctrl+Shift+Tab | Next / previous tab |
| Primary+Shift+] / [ | Next / previous tab |
| Primary+1 … 8 | Go to that tab |
| Primary+9 | Go to the last tab |
| Esc | Close an open menu or the palette |

## Command palette

↑ ↓ move, ↵ runs, Esc closes. Search finds requests and commands.

## Sidebar

↑ ↓ move, → expands, ← collapses or goes to the parent, ↵ opens or toggles, **F2** renames, **Delete** or Backspace deletes.

Preferences ▸ Shortcuts lists the main ones; **Help ▸ Keyboard Shortcuts** opens it.
